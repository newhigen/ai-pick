ai-pick UX 가이드

Curated dev-tool tracker · 디자인 레퍼런스

스캔 가능한 큐레이션 트래커의 UI/UX

ai-pick(Agent Edge)은 "AI 코딩 도구의 changelog를 매일 큐레이트해 카드로 보여주는 트래커"다. 이 아키타입의 정답 미학은 이미 업계에 정립돼 있다 — Raycast·Vercel(Geist)·Linear가 만든 개발자 도구 미학과, Product Hunt·TLDR가 다듬은 스캔형 피드 카드의 교집합. 아래는 그 레퍼런스를 분석해 ai-pick에 맞춘 토큰·규칙·체크리스트다.

1. 아키타입 — 무엇을 만드는가

두 장르의 교집합이다. 각 장르의 검증된 규칙을 빌려오되, 충돌하면 "스캔성 우선"으로 판정한다.

🛠️ 개발자 도구 미학 Raycast·Geist

뉴트럴 베이스 + 단일 액센트, 모노 숫자, 헤어라인 보더, 그림자 대신 surface 명도 사다리로 깊이. 절제가 곧 "엔지니어링 grade" 신호.

📰 스캔형 큐레이션 피드 Product Hunt·TLDR

카드 = 한 입 크기 단위. 우선 항목만 노출하고 나머지는 펼침 뒤로. 제목은 즉시 훑기 가능, 본문은 짧게 자르고 "더 있다"는 신호.

판정 원칙: 정보 밀도와 절제가 충돌하면 progressive disclosure로 푼다 — 카드 면엔 "이게 뭔지"만, 디테일은 호버/모달 뒤로. 연구상 단계적 노출은 초기 완료를 30–50% 빠르게 한다.

2. 레퍼런스 분석 — 무엇을 빌려올까

각 제품에서 ai-pick에 이식할 핵심 한 가지씩.

Raycast changelog + 마케팅
  • 그림자 0 — 깊이는 surface 명도 4단(canvas→surface→elevated→card)으로만.
  • 헤어라인 보더 1px가 유일한 카드 엣지 처리.
  • 액센트는 일러스트/카테고리에만, chrome(버튼·링크)은 무채색 유지.
  • changelog는 benefit-first — "기능"이 아니라 "얻는 가치"로 표제.
Vercel Geist design system
  • 모노 숫자(tabular)를 버전·메트릭·타임스탬프에 — "기술적"으로 읽힘.
  • 뉴트럴 우선, 액센트(#0070f3)는 "구두점처럼" 드물게.
  • 다크 우선 설계, 라이트는 2순위.
  • 여백을 아끼지 마라 — breathing room이 premium 신호.
Linear 2025 트렌드
  • 색을 더 깎아냄 — 단색 + 극소수 강조색. 선택지를 최소로.
  • 직선적·직접적 — 장식보다 명료한 위계.
Product Hunt / TLDR 큐레이션 피드
  • 카드 그리드 = 다양 콘텐츠 정렬·강조의 기본기.
  • 5분 안에 훑기 — 제목 스캔성 + 1–2문장 요약.
  • 이미지 쓰면 일정 종횡비 고정해 그리드 리듬 유지.

4. 카드 해부 · 밀도 — "더 줄일까?"의 답

써볼 카드의 각 요소가 자기 자리를 버는지 심사. 데스크톱에선 왜/학습이 이미 호버 팝오버(높이 0)라, 카드 면 = cmd + 제목 + 설명 + 메타.

날짜·가격·폴백 같은 디테일은 카드 면에서 빼 왜/학습 팝오버·클릭 모달로. 날짜는 카드 우상단 heatmap이 이미 표시 → 본문 중복. cmd 칩 키워드를 설명 끝에 반복 금지.

판정: 더 줄일 수 있나?

현재 카드는 바닥 근처다. 폰트·패딩을 더 깎으면 "이게 뭔지" 스캔성과 위계가 깨진다. 남은 건 구조적 레버 — 무작정 축소가 아니다:

  • (권장) 메타 1줄 합치기 — tier ★ + 버전 + 며칠전을 한 baseline 행으로(현재 ver는 별도 행). 카드당 1줄 절감, 모노 숫자로 통일.
  • (선택) 다크에서 그림자 제거 → 헤어라인+surface만. 시각 노이즈↓, 더 촘촘해 보임(Raycast 방식).
  • (여유 시) 밀도 토글 — 편안/컴팩트. 줄이기 vs 읽기 취향을 사용자에게.
  • 그리드 gap 14→12, minmax(264→240px)로 한 행에 카드 더.

하지 말 것: 본문 폰트 추가 축소, 제목 2줄→1줄 강제 말줄임(도구명이 잘림), tier 뱃지 제거(우선순위 신호 상실).

5. 트래커 고유 UX — changelog를 픽으로

Raycast changelog 분석에서 추출한, "릴리즈 트래커"에 특화된 규칙.

① benefit-first 표제

"기능 추가"가 아니라 "얻는 가치". "여러 턴 자율 실행" > "/goal 명령". 제목=가치, 명령어=칩.

② 토픽 태그·카테고리

용도별(🚀긴작업·📝리뷰·💰비용…) 필터로 발견성↑. Raycast가 못 한 부분 — ai-pick은 이미 "용도별" 탭으로 보유.

③ 시간 그룹 · 신선도

주/월 그룹 + 며칠전 heatmap(최근=따뜻→오래=회색). 무엇이 새 것인지 즉시.

④ 30초 스캔 흐름

맥락→이름→(스샷/데모)→사용예→링크. 카드 면은 앞 2개, 나머지는 모달.

6. ai-pick 적용 체크리스트

현재 사이트 기준. ✓=이미 충족, □=다음 레버.

  • 단일 액센트(보라) + 뉴트럴 베이스chrome 무채색, tier·cmd칩에만 액센트 — 충족
  • progressive disclosure왜/학습 = 데스크톱 호버 팝오버, 카드 높이 고정 — 충족
  • benefit-first 1줄 설명최근 컴팩트 작업서 적용 + curate_prompt에 ≤90자 규칙 — 충족
  • 며칠전 heatmap 신선도상대시간 warm→cool 색 — 충족
  • 메타 1줄 합치기tier ★ + 버전 + 날짜를 한 baseline 행으로 → 카드당 1줄 절감
  • 모노 숫자(tnum) 일관 적용버전·날짜·메트릭 전부 mono+tabular로
  • 다크 그림자 제거헤어라인+surface 명도만으로 깊이(Raycast)
  • 밀도 토글(편안/컴팩트)여유 시. 줄이기 vs 읽기 취향 위임
